## 📖 História do projeto

Este projeto nasceu durante meus estudos como uma aventura interativa feita com HTML, CSS e JavaScript. O objetivo era aprender a transformar escolhas do usuário em diferentes caminhos de uma história.

Em 2026 voltei ao projeto para preservar esse começo, mas aplicar conhecimentos que adquiri depois. Mantive a essência e as imagens originais, enquanto reconstruí a experiência visual e a navegação.

### Antes

- Estrutura simples de exercício escolar
- Uma tela por etapa da história
- Navegação apenas para avançar
- CSS básico e pouco adaptável a diferentes telas

### Hoje

- Interface de aventura mais imersiva
- Caminhos e finais alternativos
- Histórico da jornada, voltar e recomeçar
- Indicador de progresso
- Animações e feedback visual
- Layout responsivo para celular e desktop
- Melhorias de acessibilidade e organização do código
- 100% estático: sem backend, banco de dados ou Supabase

## 🧠 O que aprendi

Este projeto representa meus primeiros contatos com **HTML semântico, estilização com CSS, manipulação do DOM, eventos e lógica de navegação em JavaScript**. Revitalizá-lo também foi uma forma de comparar minhas decisões antigas com a maneira como desenvolvo interfaces hoje.
