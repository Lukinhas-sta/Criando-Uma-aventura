# Em Busca da Cidade Perdida

Projeto escolar de aventura interativa preservado como parte da minha evolução no desenvolvimento web.

## Sobre

A versão original foi criada com HTML, CSS e JavaScript para contar uma história de escolhas. Em 2026, o projeto foi revitalizado sem backend e sem banco de dados, mantendo a ideia original e melhorando a experiência visual, responsividade, acessibilidade e navegação.

## Recursos

- História com caminhos diferentes e finais alternativos
- Navegação por escolhas
- Botões de voltar e recomeçar
- Indicador de progresso
- Layout responsivo para celular e desktop
- Uso das imagens originais do projeto
- Sem dependência de backend ou Supabase

## Tecnologias

HTML5, CSS3 e JavaScript puro.

> Projeto preservado para registrar minha evolução desde os primeiros estudos de desenvolvimento web.
